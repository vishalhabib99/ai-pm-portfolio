# Case Studies

Post-launch writeups. Each one should cover:

1. **What shipped** — the actual feature, in plain terms
2. **Key decisions & tradeoffs** — what alternatives were considered and why this path won
3. **What broke / what didn't work** — honest account of failures along the way
4. **Outcome** — the metric(s) that moved, with numbers

Add one file per case study, named `YYYY-MM-feature-name.md`.
