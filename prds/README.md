# PRDs

Product requirement docs for AI features. Each PRD should cover:

1. **Problem** — what user/business problem this addresses, with evidence
2. **Users & use cases** — who this is for, top 2-3 scenarios
3. **Solution approach** — what's being built, why this approach (prompting vs RAG vs fine-tune vs agent) over the alternatives
4. **Success metrics** — the number(s) that prove this worked
5. **Evaluation plan** — how quality/safety is measured before and after launch
6. **Risks & scope cuts** — what's explicitly out of scope, known failure modes

Add one file per PRD, named `YYYY-MM-feature-name.md`.
