# Plan Limits

Each plan has a monthly usage limit shown under Settings > Usage. The Starter plan allows 10,000 API calls/month, Pro allows 100,000, and Enterprise is custom. When you hit 90% of your limit we send a warning email. At 100%, additional requests return a 429 error until the next billing cycle resets usage, or you can upgrade your plan immediately from Settings > Billing to raise the limit without waiting for the reset.
