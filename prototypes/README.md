# Prototypes

Small, working builds — not production code, but real enough to prove the idea and inform the PRD/case study next to them.

Good candidates: a RAG pipeline over a real doc set, an eval harness comparing prompt variants, a small agent that completes a defined task, a cost/latency benchmark across models.

Add one folder per prototype, named `feature-name/`, with its own README explaining what it does and how to run it.
